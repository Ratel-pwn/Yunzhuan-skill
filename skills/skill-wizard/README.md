# skill-wizard

通过对话引导，帮助用户从零开始创建一个完整、可复用的 Skill。

## 何时使用

- 想创建一个新的 Skill，但不知道从何下手
- 有一个重复性的工作流，想把它固化为 Skill
- 刚完成一个任务，想把过程保存为可复用的 Skill
- 有一个模糊的想法，需要有人帮忙梳理成具体的 Skill
- 已经有 Skill 初稿，想要专业审查和改进建议

## 使用方式

直接告诉 AI 你想创建一个 Skill，比如：

- "帮我创建一个 skill"
- "我想做一个自动生成周报的 skill"
- "把刚才的流程保存为 skill"
- "我有个想法想变成 skill"
- "帮我看看这个 skill 写得怎么样"

## 对话流程

Skill Wizard 通过 5 个阶段的对话引导你完成：

1. **破冰** — 理解你想做什么（支持快速通道，信息充足时直接跳过）
2. **细化** — 明确输入、输出、边界、语言选择
3. **起草** — 生成 SKILL.md + 质量自检 + description 打磨
4. **验证** — 用测试用例试运行（支持 subagent 并行/串行两种模式）
5. **交付** — 安装到合适的位置

你可以随时说"跳过"来略过某个阶段，也可以一次性提供所有信息走快速通道。

## 输出

- `SKILL.md` — 核心指令文件（必需）
- `README.md` — 面向人类的说明（推荐）
- `scripts/` — 辅助脚本（按需）
- `references/` — 参考文档（按需）
- `examples/` — 示例（按需）

## 质量保障

每个生成的 Skill 都会通过 8 项质量自检：

1. Frontmatter 完整性
2. Description 触发覆盖度
3. 输入/输出说明
4. 具体示例
5. 边界/排除说明
6. 无硬编码敏感信息
7. 引用路径正确性
8. 总长度合理性

## 与 skill-creator 的区别

| 特点 | skill-wizard | skill-creator |
|------|-------------|---------------|
| 定位 | 对话引导，从零到一 | 完整工程化，创建+评估+优化 |
| 适合 | 初次创建或快速迭代 | 需要系统评估和 benchmark 的场景 |
| 流程 | 轻量级对话 5 步走 | 包含 benchmark、blind comparison 等 |
| 输出 | 可用的 Skill 文件 | Skill + 评估报告 + 优化建议 |

建议：先用 skill-wizard 快速生成初版，再用 skill-creator 进行深度优化。
